# my-learning-platform

## About
A responsive online learning website built using React. It provides information about courses, student testimonials, and navigation options.

## Components
- **Header** – Navigation bar.
- **CourseList** – Displays available courses.
- **Testimonials** – Displays student reviews.
- **Footer** – Contact details and social media links.

## Technologies Used
- React.js
- HTML
- CSS
- JavaScript

## Features
- Responsive design
- Course cards
- Student testimonials
- User-friendly interface

## Author
Created as a React component-based project.
